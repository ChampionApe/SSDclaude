C4. Other parameters

The counterfactuals across the intertemporal and the Frisch elasticity

The figure shows the endogenous design of the U.S. across the intertemporal elasticity ρ, at the paper’s Frisch elasticity, and across the Frisch elasticity ξ, under log preferences. Each value is a separate calibration with its own cost parameter, which falls steeply as the IES rises (table 4 of the paper) and a little as the Frisch elasticity rises. Across the IES the figure holds every counterfactual of the paper’s figure 7.1. Across the Frisch elasticity only acute ageing is computed: the design it leads the electorate to choose is the same at every ξ, while the tax rate rises by less at a higher Frisch elasticity, whether the design is pinned or chosen.

\(\cdot\)

Figure C4.1. The endogenous design across the intertemporal and the Frisch elasticity, U.S.
import {counterfactuals, pathGrid, control, ROWS_CHOSEN, RHO, XI, CHOSEN_OUTCOMES, OUTCOMES, seriesColours} from "./assets/oa.js"
esc = FileAttachment("_generated/data/ESC_Counterfactuals.csv").csv({typed: true})
escPaths = FileAttachment("_generated/data/ESC_Paths.csv").csv({typed: true})
usObserved = esc.find(d => d.host === "US" && d.outcome === "theta" && d.reading === "pinned").baseline
ACROSS = [["the intertemporal elasticity ρ", "rho"], ["the Frisch elasticity ξ", "xi"]]
viewof c4Across = control("radio", ACROSS, {key: "across", label: "Compare across", value: "rho"})
viewof c4Out = control("radio", CHOSEN_OUTCOMES, {key: "outcome", label: "Outcome", value: "theta"})
{
  const label = c4Across === "rho" ? "U.S., ξ = 0.3" : "U.S., ρ = 1";
  return counterfactuals(esc.filter(d => d.host === "US" && d.spec === "size" && d.source === (c4Across === "rho" ? "main" : "xi")),
    {rows: ROWS_CHOSEN, series: c4Across === "rho" ? RHO : XI, outcome: c4Out, mode: "chosen",
     width, observed: {[label]: usObserved}, facets: [{label, filter: d => true}]});
}

\(\cdot\)

Note: As figure C2.1, for the U.S. Across \(\xi\) the model is recalibrated at each value under log preferences (\(\rho = 1\)), the cost parameter included; only acute ageing is computed there.

The baseline path across the elasticities

Along the baseline path the chosen design rises with ageing at every ρ and every ξ. Across the Frisch elasticity the paths nearly coincide. Across the IES the design reaches a similar level by 2110, and before 2020 it lies below the observed design at every IES, by more at the lowest and the highest.

\(\cdot\)

Figure C4.2. The baseline path across the intertemporal and the Frisch elasticity, U.S.
PATHVARS = [["Pension design θ", "theta"], ["Tax rate", "tau"], ["Savings over GDP", "sr"], ["Workweek", "workweek"]]
viewof c4pAcross = control("radio", ACROSS, {key: "across2", label: "Compare across", value: "rho"})
viewof c4pVar = control("select", PATHVARS, {key: "variable", label: "Beside workers per retiree", value: "theta"})
viewof c4pRead = control("radio", [["design chosen", "chosen"], ["design pinned", "pinned"]], {key: "reading", label: "Reading", value: "chosen"})
{
  const spec = c4pAcross === "rho" ? RHO : XI;
  const colours = seriesColours(spec.values);
  const rows = escPaths.filter(d => d.country === "US" && d.spec === "size" && d.wedgeFrom === "US"
    && (c4pAcross === "rho" ? d.source === "main" : d.source === "xi"));
  const lines = v => spec.values.map((s, i) => ({label: spec.labels[i], colour: colours.get(s),
    records: rows.filter(d => d.variable === v && Math.abs(d[spec.field] - s) < 1e-9)
                 .map(d => ({year: d.year, value: v === "nu" ? d.chosen : d[c4pRead]})).sort((a, b) => a.year - b.year)}));
  return pathGrid([{title: "Workers per retiree ν", variable: "nu", lines: lines("nu").slice(0, 1).map(l => ({...l, colour: "#52514e", label: "U.S."})),
                    rule: 2020, ruleLabel: "calibration"},
                   {title: OUTCOMES[c4pVar].level, variable: c4pVar, lines: lines(c4pVar), rule: 2020, ruleLabel: "calibration"}],
                  spec.values.map((s, i) => ({label: spec.labels[i], colour: colours.get(s), shape: "line"})), {width});
}
