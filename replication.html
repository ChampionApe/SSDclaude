OA.6 Replication

Every table and figure of the paper’s quantitative sections and of this appendix, except the paper’s figure 5.1 of Argentina’s beneficiaries, is produced by the pipeline in python/paper of the repository, in three stages: the calibrations, the experiments, and a build that reads only their results and writes the exhibits in seconds. REPLICATION.md in the repository is the map from data and code to every output, with the commands and the time each stage takes; the technical documentation (Berg and Gonzalez-Eiras 2026) describes the model, its equilibria and the algorithms.

The table lists every exhibit shown here, where it appears and the builder that makes it, with the files it reads; each exhibit’s Source has the same, with downloads and the command that rebuilds it.
