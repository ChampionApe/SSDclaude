D3. Replication

Every table and figure of this appendix is produced by the pipeline in python/paper of the repository, in three stages: the calibrations, the experiments, and a build that reads only their results and writes the exhibits in seconds. REPLICATION.md in the repository maps the data and the code to every output, with the commands and the time each stage takes; the technical documentation (Berg and Gonzalez-Eiras 2026) describes the model, its equilibria and the algorithms. The interactive figures draw from csv files that the build writes from the same results, and each figure’s Data link downloads its file.

The table lists every exhibit of this appendix, the output that holds it, the builder that makes it and the results files it reads; each exhibit’s Source has the same, with the command that rebuilds it.
