\subsection{The economic equilibrium}\label{\refsec:EE}

\smalltitle{With log preferences.}
Assume that we know the path of taxes $\tau_t$, pension characteristics $\theta_t, \epsilon_t$, and an initial exogenous level of savings $s_0$. With log preferences $B_{t+1}^i = \beta_{t,i}$, and the economic equilibrium follows without any numerical root finding:
\begin{itemize}
    \item First compute $\Gamma_{s,t}$ from \eqref{\refeq:auxiliary:Gammas} (only defined for $t<T$).
    \item Then, compute finite horizon $\Theta_{h,t}$ from stacking \eqref{\refeq:auxiliary:Thetah} for $t<T$ and \eqref{\refeq:auxiliary:ThetahT} for $t=T$.
    \item Then, compute $\Theta_{s,t}$ from \eqref{\refeq:auxiliary:Thetas} (only defined for $t<T$ as well).
    \item Given $s_0$ and $\Theta_{s,t}$ we can iterate forward on \eqref{\refeq:auxiliary:s} to solve for $s_t$ for all $t<T$. For $t=T$ we have $s_T = 0$ per construction.
\end{itemize}
As explained in \cref{\refmodelsec}, this set of core variables allows us to solve for individual labour supply and savings, factor prices, pension benefits, and finally consumption levels (from budgets).

The informal savings ratio $\iota_t$ is \emph{not} part of this core. Informal savings do not enter the formal capital stock, so none of $\Gamma_{s,t}, \Theta_{h,t}, \Theta_{s,t}, s_t, h_t$ depends on them. Once the core is solved, $\iota_t$ follows in closed form from \eqref{\refeq:auxiliary:s0_s}, and is defined for $t<T$ only (at $t=T$ the informal, like the formal, save nothing). The same applies with CRRA preferences below, with $B_{t+1}^0$ evaluated at the solved $\left(s_t, h_{t+1}\right)$.


\smalltitle{With CRRA preferences.}
Given the same inputs, the core of the economic equilibrium is the vectors $\Gamma_{s,t}, h_t, s_t$, identified by a square system of nonlinear equations:
\begin{itemize}
    \item $h_t$ satisfies \eqref{\refeq:auxiliary:h}, with $\Theta_{h,t}$ from \eqref{\refeq:auxiliary:Thetah} for $t<T$ and \eqref{\refeq:auxiliary:ThetahT} for $t=T$;
    \item $s_t$ satisfies \eqref{\refeq:auxiliary:sFromH} for $t<T$, with $s_T = 0$;
    \item $\Gamma_{s,t}$ satisfies \eqref{\refeq:auxiliary:Gammas} for $t<T$, with $B_{t+1}^i(s_t, h_{t+1})$ from \eqref{\refeq:auxiliary:B}.
\end{itemize}
The system is solved by a standard nonlinear root finder from the log closed form, unless a warm start is supplied. Given its solution $(s_t, h_t, \Gamma_{s,t})$, the rest of the outcomes follow as in the log case.


\smalltitle{Initializing with steady state savings.}
When we solve for the economic equilibrium given vectors of $\tau_t, \theta_t$, and $\epsilon_t$, our default option for the initial exogenous level of savings $s_0$ is to solve for steady state levels using parameter values from the first period ($t=1$).

With log preferences, $B^i = \beta_i$ and $\Gamma_{s}$ follows in closed form from \eqref{\refeq:auxiliary:Gammas}. The steady state is then
\begin{subequations}\label{\refeq:steadystate_LOG}
    \begin{align}
        \Gamma_s =& \frac{1}{1+\xi}\frac{\sum_i \frac{\gamma_{i}\eta_{i}^{1+\xi}}{X_{i}^{\xi}}\frac{B^i}{1+B^i}}{1+\frac{1-\alpha}{\alpha}\frac{p\tau}{\kappa}\left(\theta+(1-\theta)\sum_i\frac{\gamma_{i}}{1+B^i}\right)} \label{\refeq:steadystate_LOG:Gammas}\\
         s^* =& \Gamma_h^{1+\xi}\left[\left(\frac{(1-\alpha)(1-\tau)}{\Gamma_h-\frac{1-\alpha}{\alpha}\frac{p\theta\tau}{\kappa}\Gamma_s}\right)^{1+\xi}\frac{\Gamma_s^{1+\alpha\xi}}{\nu^{\alpha(1+\xi)}}\right]^{\frac{1}{1-\alpha}} \label{\refeq:steadystate_LOG:s}
    \end{align}
\end{subequations}

With CRRA preferences, $s^*$ has to be identified numerically. We solve for it as a bounded scalar root in $\Gamma_s$, for which robust and fast algorithms are available: $\Gamma_s$ solves
\begin{subequations}\label{\refeq:steadystate_CRRA}
\begin{align}
    &\Gamma_s(1+\xi)\left[1+\frac{1-\alpha}{\alpha}\frac{p\tau}{\kappa}\left(\theta+(1-\theta)\sum_i\frac{\gamma_i}{1+B^i(\Gamma_s)}\right)\right] = \sum_i\frac{\gamma_i\eta_i^{1+\xi}}{X_i^{\xi}} \frac{B^i(\Gamma_s)}{1+B^i(\Gamma_s)}, \label{\refeq:steadystate_CRRA:Gammas} \\
    &\text{where }B^i(\Gamma_s) = \left(\beta_i\right)^{\rho} \left(\frac{\alpha}{p}\frac{\Gamma_h-\frac{1-\alpha}{\alpha}\frac{p\theta\tau}{\kappa}\Gamma_s}{(1-\alpha)(1-\tau)}\frac{\nu}{\Gamma_s}   \right)^{\rho-1}, \label{\refeq:steadystate_CRRA:Bi}
\end{align}
\end{subequations}
and $s^*$ follows from $\Gamma_s$ as in the log case. The bracket in \eqref{\refeq:steadystate_CRRA:Bi}, and with it the denominator of $\Theta_h$ in \eqref{\refeq:auxiliary:Thetah}, vanishes at
\begin{align*}
    \overline{\Gamma}_s = \frac{\alpha\kappa\,\Gamma_h}{(1-\alpha)p\theta\tau},
\end{align*}
infinite when $\theta\tau = 0$. Above it the fractional power is undefined, and the steady state lies strictly below it. We use Brent's method on the bracket $\left(10^{-6}, \min\lbrace 0.75,\, 0.99\,\overline{\Gamma}_s\rbrace\right)$. Since $\overline{\Gamma}_s$ scales with $\alpha/(1-\alpha)$, the constant $0.75$ is not a bracket by construction; where the default bracket shows no sign change, its upper end is doubled, up to $0.99\,\overline{\Gamma}_s$, until it does.
