\subsection{Recovering the equilibrium path}\label{\refsec:PEEpath}
Algorithms \ref{\refalg:LOG:gridsearch} and \ref{\refalg:CRRA:grid} identify policy \emph{functions}, not a path: at each $t$ they return $\tau_t$ as a function of the state inherited from $t-1$. To report a politico-economic equilibrium we still have to pin down the state entering the first period and then walk the functions forward, in both preference cases.

\smalltitle{The initial state is a scalar fixed point.}
Following \cref{\refsec:EE}, the pre-determined period is given by a steady state assumption: the generation that is old in the first active period behaved as if it had always faced the policy it meets there. That policy is itself what we are solving for, which makes this a fixed point. Write the first active period as $t=1$ and let $\tau_1$ denote the tax chosen there. A constant policy $\tau_1$ delivers a steady-state coefficient function $\Theta_s(\tau_1)$ from \eqref{\refeq:steadystate_LOG} or \eqref{\refeq:steadystate_CRRA} as appropriate, and hence
\begin{subequations}\label{\refeq:initialState}
\begin{align}
    \iota_0 &= \iota_0\left(B_1^0(\tau_1),\, \Theta_s(\tau_1),\, \tau_1\right), \label{\refeq:initialState:iota}\\
    s_0 &= s^*(\tau_1), \label{\refeq:initialState:s}
\end{align}
\end{subequations}
where \eqref{\refeq:initialState:iota} is \eqref{\refeq:auxiliary:s0_s} evaluated at a constant policy and \eqref{\refeq:initialState:s} is the steady-state savings level. Both are functions of $\tau_1$ alone. Closing the loop with the solved first-period policy function gives the residual
\begin{align}\label{\refeq:initialFixedPoint}
    \tau_1 - \tau^{1}\left(\iota_0(\tau_1)\right) = 0 \quad\text{(log)}, \qquad\qquad
    \tau_1 - \tau^{1}\left(s_0(\tau_1),\, \iota_0(\tau_1)\right) = 0 \quad\text{(CRRA)},
\end{align}
a scalar problem in both cases. We search over $\tau_1$ rather than over the states: $\tau_1$ has known bounds $[l,u]$, whereas any bracket for $s_0$ or $\iota_0$ would have to be inferred from the steady-state map being inverted. Under log preferences $s_0$ is not a political state; it is resolved from \eqref{\refeq:initialState:s} at the converged $\tau_1$ and used only to report levels.

\smalltitle{A guaranteed bracket, and a spurious root.}
Evaluating $\tau^1(\cdot)$ in \eqref{\refeq:initialFixedPoint} means clipping it back into $[l,u]$, so the residual is weakly negative at $l$ and weakly positive at $u$ whatever the policy function does. That bracket is not safe to hand to a bracketed solver. As $\tau_1\rightarrow 1$ the steady state degenerates and $\iota_0$ diverges, because its denominator, formal savings, collapses, so the map $\tau_1\mapsto(s_0,\iota_0)$ of \eqref{\refeq:initialState} leaves the grids the policy functions were solved on. There $\tau^1(\cdot)$ is extrapolated and then clipped, and an extrapolated value above $u$ makes the residual at $\tau_1 = u$ \emph{exactly} zero: the clip manufactures a root at the bracket end, a bracketed solver accepts it, and the reported equilibrium is the degenerate steady state. Whether this happens depends on how the extrapolation falls, so the hazard is intermittent.

Two corrections follow. First, the residual is left undefined wherever $(s_0,\iota_0)$ leaves $\mathcal{S}\times\mathcal{S}_0$ (in the log case, wherever $\iota_0\notin\mathcal{S}_0$): a state that leaves the grid is reported, never clipped back onto it. Second, \eqref{\refeq:initialFixedPoint} need not have a unique root. We evaluate the residual on $\mathcal{T}$, discard the nodes whose implied state leaves the grids, locate the sign changes between adjacent surviving nodes, and refine the lowest with a bracketed solver inside its cell, the convention of the state fixed points (\cref{\refsec:RobustRoot}). The number of crossings is reported, an exact zero at a node counting as one. If no sign change survives, either the state grids are too narrow for the steady states $\mathcal{T}$ implies or no constant policy reproduces itself through the first period's policy function, and the solve fails.

\smalltitle{Forward simulation.}
With $(s_0,\iota_0)$ in hand, walk forward for $t = 1,...,T$, reading the tax off the solved policy function and the next state off the solved state policy functions:
\begin{align}\label{\refeq:forwardSim}
    \begin{array}{lll}
    \text{(log)} & \tau_t = \tau^t\left(\iota_{t-1}\right), & \iota_t = \iota_t\left(\tau_t\right), \\[4pt]
    \text{(CRRA)} & \tau_t = \tau^t\left(s_{t-1},\iota_{t-1}\right), \qquad & s_t = s_t\left(\tau_t, s_{t-1}\right),\quad \iota_t = \iota_t\left(\tau_t,s_t\right).
    \end{array}
\end{align}
The state transitions are written as functions of the tax, and that is meant literally: they are \emph{re-solved} at the simulated $\tau_t$, one scalar root per period, not read off an interpolant of the selected states over the predetermined ones, which would interpolate a composition that the re-solve evaluates directly and, in the log case, give up the result of \cref{\refsec:PEELOG} that the predetermined state does not enter the fixed point.

Three checks belong here. First, the state entering each period, at which the policy function is evaluated, must stay where the policy functions mean something: $\iota_{t-1}\in[l_{\iota},u_{\iota}]$ in the log case, and in the CRRA case $(s_{t-1},\iota_{t-1})$ inside the reachable set $\mathcal{P}_{t-1}$ of \eqref{\refeq:reachable} from the second period on. $\mathcal{P}_t$ is recorded as the image of the state grid, a finite set of pairs, so the test is against its bounding box, which contains $\mathcal{P}_t$: a pair outside the box lies outside $\mathcal{P}_t$ for certain. A path that leaves either set is driven by extrapolated policy and is reported as unreliable, not returned. Second, each $\tau_t$ is checked against the corners $l$ and $u$: a path that pins to a corner for several periods usually indicates a grid or calibration problem rather than an economic result. Third, in the CRRA case only, the simulation tests that what it reads is defined: the policy surfaces are undefined at their infeasible nodes, and a two-dimensional interpolant cannot be restricted to its feasible nodes as the one-dimensional interpolants of \cref{\refsec:PEELOG} are, so a path can become undefined without leaving $\mathcal{S}\times\mathcal{S}_0$.

\smalltitle{The simulated path is never reported directly.}
The tax path from \eqref{\refeq:forwardSim} is accurate only to the resolution of the grids and the interpolants, and the allocation implied by the walk satisfies the equilibrium conditions only approximately. We therefore take from the simulation only $\bm{\tau}$ and the initial state $s_0$, and re-solve the economic equilibrium of \cref{\refsec:EE} \emph{exactly} at that policy path, in closed form in the log case and as the square nonlinear system in the CRRA case, warm-started at the simulated $\left(\Gamma_{s,t},h_t,s_t\right)$. Everything reported downstream, including $\iota_t$ and all consumption levels, is read off that exact solution: the grid search locates the branch, and the exact step recovers machine precision on it. The $\iota_t$ path from the exact re-solve should agree with the simulated one to well inside a cell of $\mathcal{S}_0$ (or $\mathcal{S}$); a larger gap means the state grid is too coarse for the dynamics, an error that the first order condition residual, evaluated on the grid, cannot see.
